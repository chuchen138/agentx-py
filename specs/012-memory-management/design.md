# 记忆管理（Memory Management）技术设计

## 技术架构

### 整体架构

记忆管理模块采用分层架构设计，遵循领域驱动设计原则。接口层提供 RESTful API，包含 PortalMemoryController 和 DTO。应用层包含 MemoryAppService 和 Assemblers，负责编排领域服务。领域层包含 MemoryDomainService、MemoryExtractorService、领域模型、仓储接口和常量。基础设施层包含记忆仓储实现、向量存储接口和数据库。

### 组件层次

接口层提供对外 RESTful API 接口、创建记忆请求、查询记忆请求、记忆条目数据传输对象。应用层提供分页查询用户记忆、手动创建记忆、归档删除记忆、实体与 DTO 转换、命令对象转换。领域层提供记忆领域服务（保存记忆包括去重/合并+向量入库、记忆检索包括相似度+重要性加权、查询记忆列表、归档记忆）、记忆抽取服务（异步抽取并持久化、从用户消息中抽取候选记忆）、领域模型（记忆条目实体、候选记忆、检索结果、记忆类型枚举）、记忆仓储接口、向量元数据键名常量。基础设施层提供记忆仓储实现（MyBatis-Plus）、向量存储接口（LangChain4j 抽象）、数据库（memory_items 表）。

## 向量存储策略

向量化流程包括文本标准化处理、嵌入模型生成、构建文本段加元数据、写入向量存储。嵌入模型配置使用用户专属的嵌入模型配置，通过 UserModelConfigResolver 解析配置，通过 EmbeddingModelFactory 动态创建模型实例，每个用户使用独立的嵌入模型配置。

向量元数据包括归属用户 ID（用于检索过滤）、记忆条目 ID（关联业务数据）、记忆类型、标签列表、状态（1=active）。

## 相似度算法

检索流程包括查询向量生成、向量相似度检索、状态过滤、计算加权和、排序并截取 Top-K。相似度检索使用 LangChain4j 的 EmbeddingSearchRequest，过滤条件为仅召回本用户记忆、最低相似度阈值 0.3，召回数量为候选加倍后续加权筛选。最终评分采用线性加权策略，加权评分为 0.7 乘以相似度权重加上 0.3 乘以重要性权重。

## 记忆提取

记忆抽取在每轮对话结束后自动触发，采用异步处理方式。抽取模型使用用户默认的聊天模型（ChatModel），通过 LLMProviderService.getStrand() 获取，支持多种 LLM 协议。抽取服务使用结构化的 System Prompt，指导 LLM 进行记忆提取。Prompt 关键要素包括类型定义（明确定义四种记忆类型及其含义）、不抽取判定（明确列出不应抽取的内容类型）、提取规则（说明重要性评分标准和提取阈值）、输出格式（指定 XML 格式输出要求）、示例说明（提供典型示例确保理解一致性）。

抽取阈值包括基本阈值 importance ≥ 0.8、EPISODIC 阈值 importance ≥ 0.9（更严格）、输出数量限制（最多输出 1-3 条最高价值要点）。XML 解析使用标准的 XML 解析器处理 LLM 返回的 XML 格式，解析记忆类型、文本、重要性、标签，生成候选记忆列表。

## 去重与合并策略

去重机制包括文本标准化（合并多行、合并空白、去除首尾空白、转小写）、哈希生成（使用 SHA-256 算法生成语义哈希）、去重查询（根据用户 ID 和去重哈希查询）。

合并策略当检测到重复记忆时，importance 取最大值，tags 合并并去重，data 智能合并，text 选择文本更丰富的版本。合并时新增记忆条目，设置用户 ID、类型、文本、数据、重要性、标签、源会话 ID、去重哈希、状态，插入到数据库。

## 数据模型

记忆条目实体包含 ID（主键）、用户 ID、类型、文本、额外数据（JSON）、重要性、标签列表、源会话 ID、去重哈希、状态、创建时间、更新时间、删除时间。候选记忆包含类型、文本、额外数据、重要性、标签。记忆类型包括 PROFILE（用户画像）、TASK（任务目标）、FACT（事实信息）、EPISODIC（ episodical 记忆）。

## 核心流程

保存记忆流程包括接收候选记忆列表、遍历候选记忆、文本标准化、生成去重哈希、查询重复记忆、存在则合并更新 importance 和 tags、不存在则新增、构建向量元数据、生成嵌入向量、写入向量存储、返回保存结果。

记忆检索流程包括查询字符串、查询向量生成、向量相似度检索、状态过滤、计算加权评分、排序并截取 Top-K、返回检索结果。

记忆抽取流程包括对话结束触发、构建抽取请求、调用抽取模型、解析 XML 响应、生成候选记忆列表、异步调用保存记忆。

## 扩展性设计

新增记忆类型在 MemoryType 枚举中添加新类型，更新抽取 Prompt 说明，更新检索过滤。新增向量存储实现实现 EmbeddingStore 接口，提供配置选项，支持热切换。新增抽取模型实现抽取服务接口，支持自定义 Prompt，支持多种 LLM 协议。

## 性能优化

向量化优化使用批量嵌入、异步处理、连接池。检索优化使用候选加倍、状态过滤、索引优化。去重优化使用哈希去重、数据库索引、缓存结果。

## 安全考虑

数据隔离使用用户 ID 过滤、向量存储过滤。数据加密使用 HTTPS 传输、敏感数据加密。访问控制使用用户鉴权、操作审计。隐私保护使用匿名化处理、可配置删除策略。

## 监控指标

关键监控指标包括记忆保存成功率、记忆检索成功率、向量嵌入成功率、抽取模型调用成功率、检索平均响应时间、抽取平均响应时间、存储内存使用量、向量索引大小、重复记忆检测准确率、相似度分布统计。告警规则包括保存失败率超过阈值、检索失败率超过阈值、抽取模型调用失败、向量存储异常、重复率异常。
