## 1. 概述

智能体管理模块是 AgentX 平台的核心能力之一，负责 AI 智能体（Agent）的全生命周期管理，包括创建、配置、版本控制、发布审核、能力集成（工具和知识库）、工作空间管理以及 Widget 嵌入配置等功能。

### 1.1 核心目标

- **灵活的智能体定义**：支持用户自定义智能体的名称、描述、系统提示词、欢迎消息等基本信息
- **强大的能力集成**：支持集成工具（Tools）和知识库（Knowledge Base）扩展智能体能力
- **完善的版本控制**：提供版本号管理、版本快照、发布审核机制，确保智能体迭代可控
- **便捷的配置管理**：支持 LLM 模型参数配置、Widget 嵌入配置、工作空间个性化配置
- **安全的访问控制**：基于用户的数据隔离、域名白名单、调用配额限制等多层安全机制

### 1.2 适用范围

本规范适用于：
- 智能体的创建、编辑、删除等基本操作
- 智能体版本发布、审核、上架、下架等版本管理
- Agent Widget 的创建、配置、嵌入代码生成等嵌入管理
- 工作空间的 Agent 管理和模型配置
- 系统提示词的 AI 辅助生成

## 2. 核心能力描述

### 2.1 智能体基础管理

#### 2.1.1 智能体创建

**功能描述**：用户可以创建新的智能体，定义其基本属性和能力配置。

**核心属性**：
- **基本信息**：名称（必填）、描述、头像
- **人设配置**：系统提示词（System Prompt）、欢迎消息（Welcome Message）
- **能力集成**：关联的工具 ID 列表、关联的知识库 ID 列表
- **工具预设参数**：支持为特定工具预先配置参数
- **多模态支持**：支持语音、图像等多模态输入输出
- **状态管理**：启用/禁用状态

**业务规则**：
- 创建时需要验证用户账户余额（涉及计费系统）
- 自动为用户创建默认的 LLM 模型配置
- 工具和知识库的引用需要验证用户的访问权限

#### 2.1.2 智能体查询

**功能描述**：支持多维度查询智能体，包括单个查询、列表查询、已上架查询等。

**查询场景**：
- **单个查询**：根据 Agent ID 查询详细信息（需权限验证）
- **列表查询**：查询当前用户的智能体列表，支持按名称、状态过滤
- **已上架查询**：查询平台上已发布可用的智能体，支持名称搜索
- **工作区查询**：查询已添加到用户工作区的智能体

#### 2.1.3 智能体更新

**功能描述**：支持更新智能体的基本信息和配置。

**支持更新**：
- 基本信息更新：名称、头像、描述
- 配置更新：系统提示词、欢迎消息、工具列表、知识库列表
- 工具预设参数更新
- 多模态配置更新

**业务规则**：
- 更新操作不影响已发布的版本
- 工具和知识库的引用需要验证用户的访问权限
- 支持"草稿"状态的自由编辑

#### 2.1.4 智能体删除

**功能描述**：删除智能体及其关联数据。

**删除范围**：
- Agent 基础信息
- 所有版本数据
- Widget 配置
- 工作空间关联
- 关联的定时任务

**业务规则**：
- 删除前验证用户权限
- 删除操作不可恢复
- 已删除的智能体无法被查询和使用

#### 2.1.5 状态管理

**功能描述**：支持智能体的启用/禁用状态切换。

**状态说明**：
- **启用**：智能体可以被正常使用
- **禁用**：智能体无法被使用，但数据保留
- 切换状态不影响已发布的版本

### 2.2 版本管理与发布审核

#### 2.2.1 版本发布

**功能描述**：支持智能体的版本化发布，为每次重大变更创建版本快照。

**版本规范**：
- 版本号遵循 `x.y.z` 格式（如 1.0.0、1.2.3）
- 版本号必须严格递增（遵循语义化版本规范）
- 每个版本保存当前的完整配置快照

**版本快照内容**：
- Agent 基本信息（名称、头像、描述）
- 系统提示词和欢迎消息
- 工具列表和工具预设参数
- 知识库列表
- 变更日志（Change Log）
- LLM 模型配置
- 多模态配置

#### 2.2.2 发布审核流程

**功能描述**：智能体发布到平台市场需要经过审核流程。

**发布状态机**：

| 状态 | 说明 | 转换条件 |
|------|------|---------|
| 审核中（REVIEWING） | 已提交审核，等待管理员审核 | 发布新版本 |
| 已发布（PUBLISHED） | 审核通过，已上架到市场 | 管理员审核通过 |
| 拒绝（REJECTED） | 审核未通过，需修改后重新提交 | 管理员审核拒绝 |
| 已下架（REMOVED） | 已发布但被下架 | 管理员下架操作 |

**审核内容**：
- 内容合规性检查
- 功能完整性验证
- 安全性审查
- 质量标准评估

#### 2.2.3 版本查询

**功能描述**：支持查询智能体的版本历史。

**查询维度**：
- 查询所有版本历史
- 查询最新版本
- 查询已发布版本
- 查询特定版本的详细信息

### 2.3 Widget 配置与嵌入

#### 2.3.1 Widget 创建

**功能描述**：为 Agent 创建 Widget 配置，支持在第三方网站嵌入使用。

**Widget 类型**：
- **Agent 类型**：使用 Agent 的完整工具流程，适合复杂场景
- **RAG 类型**：直接使用 RAG 对话流程，适合问答场景

**配置项**：
- 基本信息：名称、描述
- 模型配置：指定使用的 LLM 模型和提供商
- 访问控制：
  - 域名白名单（支持通配符，如 *.example.com）
  - 每日调用次数限制（-1 表示无限制）
- 启用状态：启用/禁用

**RAG 类型特有配置**：
- 关联的知识库 ID 列表

#### 2.3.2 Widget 访问控制

**功能描述**：提供多层访问控制机制，确保 Widget 的安全使用。

**域名白名单**：
- 支持精确域名匹配（如 www.example.com）
- 支持通配符匹配（如 *.example.com）
- 空白名单表示允许所有域名访问

**调用限制**：
- 每日调用次数控制
- 超过限制后拒绝新请求
- 支持动态调整限制值

#### 2.3.3 嵌入代码生成

**功能描述**：自动生成 Widget 的嵌入式脚本代码。

**嵌入特性**：
- 基于唯一的 Public ID 生成
- 支持自定义样式和尺寸
- 提供 JavaScript SDK 集成方式
- 支持事件回调机制

### 2.4 工作空间管理

#### 2.4.1 工作空间概念

**功能描述**：工作空间是用户管理智能体的个人工作区，支持添加其他用户发布的智能体。

**工作空间特点**：
- 每个用户拥有独立的工作空间
- 可以添加自己创建的智能体
- 可以添加其他用户已发布到市场的智能体
- 支持为工作空间中的 Agent 自定义 LLM 模型配置

#### 2.4.2 LLM 模型配置

**功能描述**：在工作空间中为智能体配置个性化的 LLM 模型参数。

**模型参数**：

| 参数 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| modelId | String | 模型 ID | - |
| temperature | Double | 温度参数，控制随机性，范围 0-2 | 0.7 |
| topP | Double | Top P 参数，控制输出多样性，范围 0-1 | 0.7 |
| topK | Integer | Top K 参数 | 50 |
| maxTokens | Integer | 最大 Token 数 | - |
| strategyType | Enum | Token 溢出策略 | NONE |
| reserveRatio | Double | 预留缓冲比例（滑动窗口策略） | - |
| summaryThreshold | Integer | 摘要触发阈值（摘要策略） | - |

**Token 溢出策略类型**：
- **NONE**：不处理，直接截断
- **SLIDING_WINDOW**：滑动窗口策略，保留最近的对话历史
- **SUMMARY**：摘要策略，对历史对话进行摘要压缩

#### 2.4.3 工作空间操作

**支持操作**：
- 添加 Agent 到工作空间
- 从工作空间移除 Agent
- 更新 Agent 的模型配置
- 查询工作空间中的 Agent 列表

### 2.5 系统提示词生成

#### 2.5.1 AI 辅助生成

**功能描述**：利用 AI 自动生成高质量的系统提示词。

**生成要素**：
- Agent 名称和描述
- 关联的工具能力概述
- 预设的使用场景

**生成模板**：
采用结构化的 XML 格式输出：
- `<role_and_personality>`：角色和个性定义
- `<capabilities_summary>`：能力摘要
- `<rules_and_framework>`：规则和框架

**生成规则**：
- "思考 -> 行动 -> 观察"的循环解决问题
- 主动利用能力满足用户请求
- 信息不足时主动提问
- 严格符合人设设定

## 3. 使用场景

### 3.1 场景一：创建客服智能体

**用户需求**：创建一个客服智能体，能够回答产品相关问题，并支持查询订单状态。

**操作流程**：
1. 创建智能体，设置名称为"产品客服"
2. 添加"订单查询工具"和"产品知识库"
3. 编写系统提示词，定义智能体的角色和服务规则
4. 配置欢迎消息，引导用户提问
5. 发布版本，提交审核

**关键特性**：
- 工具集成（查询订单）
- 知识库集成（产品文档）
- 系统提示词定制
- 版本发布审核

### 3.2 场景二：智能体网站嵌入

**用户需求**：将已发布的智能体嵌入到公司官网，为访客提供咨询服务。

**操作流程**：
1. 确认智能体已审核通过并发布
2. 为智能体创建 Widget
3. 设置域名白名单（如 www.company.com）
4. 配置每日调用限制（如 1000 次）
5. 获取嵌入代码，嵌入到网站页面

**关键特性**：
- Widget 配置
- 域名白名单控制
- 调用次数限制
- 嵌入代码生成

### 3.3 场景三：智能体迭代升级

**用户需求**：智能体 v1.0 已上线，需要在新版本中添加新工具和改进提示词。

**操作流程**：
1. 编辑智能体，添加新的工具集成
2. 优化系统提示词，改进服务质量
3. 创建新版本 v2.0，填写变更日志
4. 提交审核，等待审核通过
5. 审核通过后，v2.0 版本上线

**关键特性**：
- 版本号管理
- 版本快照
- 审核流程
- 版本历史追溯

### 3.4 场景四：个性化模型配置

**用户需求**：不同的智能体需要使用不同的 LLM 模型和参数，以满足不同场景的需求。

**操作流程**：
1. 将智能体添加到工作空间
2. 配置该智能体的 LLM 模型参数
  - 创作型智能体：temperature = 0.8（提高创造性）
  - 严谨型智能体：temperature = 0.3（减少随机性）
  - 长对话场景：启用滑动窗口策略，设置 maxTokens 和 reserveRatio

**关键特性**：
- 工作空间管理
- LLM 模型配置
- Token 溢出策略

### 3.5 场景五：AI 辅助提示词生成

**用户需求**：快速生成高质量的系统提示词，无需手动编写。

**操作流程**：
1. 填写智能体的名称和描述
2. 选择需要集成的工具
3. 调用系统提示词生成接口
4. AI 基于输入信息生成结构化的提示词
5. 用户可以后续编辑和优化生成的提示词

**关键特性**：
- AI 辅助生成
- 结构化输出
- 可编辑优化

### 4.2 技术特性

- **DDD 架构**：清晰的领域模型和分层设计

- **状态机**：版本发布审核的状态流转管理
- **权限隔离**：基于用户 ID 的数据访问控制
- **计费集成**：与计费系统的无缝集成
- **工具集成**：支持工具和知识库的灵活集成

- **快速创建**：支持 AI 辅助生成系统提示词，降低使用门槛
- **灵活配置**：支持多种 LLM 模型参数和 Token 溢出策略
- **安全可控**：域名白名单、调用限制、权限隔离等多层安全机制

## 5. 非功能性需求

### 5.1 性能要求

- 智能体创建响应时间 < 500ms
- 查询操作响应时间 < 200ms
- 版本发布处理时间 < 1s
- Widget 嵌入加载时间 < 2s

### 5.2 可用性要求

- 系统可用性 ≥ 99.9%
- 支持并发查询请求 ≥ 1000 QPS

### 5.3 安全性要求

- 数据严格基于用户 ID 隔离
- Widget 域名白名单强制执行
- API 访问需要身份认证和权限验证
- 敏感操作需要二次验证

### 5.4 可扩展性要求

- 支持水平扩展以应对增长的智能体数量
- 支持新增工具类型和知识库类型
- 支持新增 Widget 类型
- 支持自定义 Token 溢出策略

## 6. 约束条件

- 版本号必须遵循 `x.y.z` 格式且严格递增
- 发布到市场的智能体必须经过审核
- 工具和知识库的引用必须验证用户权限
- Widget 的每日调用限制不能为负数（-1 表示无限制）
- 系统提示词生成需要用户设置默认 LLM 模型
