# 内置工具技术设计

## 概述

内置工具模块采用工具提供者模式和注册表模式，实现工具的统一管理和动态扩展。支持多种工具提供者，为 Agent 和其他模块提供结构化的工具调用能力。

## 技术架构

### 整体架构

内置工具模块由工具调用方、工具注册表、工具提供者组成。BuiltInToolRegistry 作为工具注册表，维护工具注册表和管理工具提供者。通过实现 BuiltInToolProvider 接口，可以添加新的工具提供者（如 RAG、User、MCP Provider）。

### 设计模式

#### 提供者模式

将工具的提供和使用分离，通过 BuiltInToolProvider 定义提供者接口，RagBuiltInToolProvider 等实现 RAG 工具提供，BuiltInToolRegistry 管理注册表，支持动态添加工具提供者。

#### 注册表模式

集中管理所有工具，提供统一的查找接口。BuiltInToolRegistry 作为工具注册表，使用 Map 存储工具定义，支持工具的动态注册和查询。

## 核心组件

### BuiltInToolRegistry

维护工具注册表，管理工具提供者，提供工具查询和获取接口。关键成员包括工具注册表和工具提供者列表，提供注册提供者、获取工具和列表查询等方法。

### BuiltInToolProvider

定义工具提供者接口，提供工具的获取和查询能力，支持提供者的动态加载。关键方法包括获取所有工具、获取指定工具和提供者名称。

### RagBuiltInToolProvider

提供 RAG 检索工具，实现向量检索、关键词检索和混合检索。工具列表包括 rag_search（向量检索工具）、rag_hybrid_search（混合检索工具）和 rag_keyword_search（关键词检索工具）。

### ToolDefinition

定义工具的元数据，描述工具的接口和功能。关键属性包括工具名称、工具描述、输入参数、返回值定义、工具类型、工具标签和提供者标识。

## 工具注册

系统启动时，Spring 扫描所有 BuiltInToolProvider Bean 并自动收集到注册表中。BuiltInToolRegistry 从提供者注册工具，处理工具名称冲突，设置提供者信息。初始化完成后，工具可供其他模块调用。

## 工具查询

通过工具名称从注册表获取工具定义，验证参数合法性，调用工具执行逻辑，返回工具结果。支持按类型列表查询工具，过滤并返回符合条件的工具列表。

## 工具执行接口

ToolExecutor 定义工具调用接口，实现对参数验证、工具调用逻辑执行和结果返回。DefaultToolExecutor 实现该接口，自动从注册表获取工具定义，验证必需参数，执行工具逻辑并返回结果。

## 配置设计

内置工具配置支持启用开关、注册表缓存、热加载、RAG 检索参数和工具执行参数。可以配置缓存时间、默认 top-k 值、最大 top-k 值、检索超时、向量检索权重、关键词检索权重、重排序启用、工具执行超时、异步执行和最大并发数等参数。

## 关键流程

### 工具注册流程

系统启动时 Spring 扫描所有 BuiltInToolProvider Bean，BuiltInToolRegistry 初始化并收集所有 Provider，逐个调用 registerProvider 方法，Provider 注册工具到 Map 并记录注册信息，工具注册完成后可供其他模块调用。

### 工具调用流程

Agent 或用户调用工具（传递 toolName 和 parameters），ToolExecutor 从 Registry 获取 ToolDefinition，验证参数合法性，调用工具执行逻辑（RAG 检索、其他工具逻辑等），返回执行结果或错误信息，结果返回给调用方。

## 错误处理

### 异常类型

系统定义工具不存在异常（调用不存在的工具）、参数无效异常（缺少必需参数、参数类型错误、参数值超出范围）、工具执行失败异常（工具内部逻辑错误、外部依赖不可用、执行超时）和提供者注册失败异常（工具名称冲突、提供者初始化失败）。

## 性能优化

### 工具缓存

缓存工具定义，使用 Caffe/Guava Cache，支持缓存过期和刷新。

### 并发执行

支持工具的并发调用，使用线程池管理并发，限制最大并发数。

### 检索优化

向量检索使用索引加速，结果缓存，批量检索减少网络往返。

## 监控指标

### 关键指标

监控各工具调用次数、平均响应时间、成功/失败率，RAG 检索请求数、平均检索时间、平均结果数，各提供者的健康状态、工具注册数量等关键指标。

### 告警规则

设置工具调用失败率过高、RAG 检索延迟过高、参数验证失败频繁等告警规则。

## 扩展性

### 新增工具提供者

实现 BuiltInToolProvider 接口，使用 @Component 注解标记提供者，提供者自动注册到工厂。

### 新增工具类型

在 ToolDefinition 中定义新的工具类型，扩展参数和返回值定义。
