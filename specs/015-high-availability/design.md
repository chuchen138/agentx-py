# 高可用（High Availability）- 设计文档

## 架构设计

### 整体架构

高可用模块采用网关模式，通过高可用网关统一管理所有模型实例，实现故障切换、负载均衡和健康检查。系统包含领域服务层（业务逻辑决策）、网关接口层（基础设施操作）和独立部署的高可用网关服务。

### 核心组件

HighAvailabilityDomainService 负责高可用的业务逻辑决策，包括模型与网关的同步管理、最佳 Provider 和 Model 选择、降级策略执行。HighAvailabilityGateway 定义基础设施层的操作接口，与高可用网关服务进行通信，封装底层网络调用细节。HighAvailabilityEventListener 监听模型生命周期事件，触发模型同步操作，异步处理网关更新。

## 设计模式

网关模式通过 HighAvailabilityGateway 封装跨领域的复杂交互，提供统一的接口，屏蔽底层 RPC 调用细节。监听器模式通过 HighAvailabilityEventListener 监听领域事件，事件触发后异步执行同步操作，解耦模型管理和高可用逻辑。降级模式在网关不可用时降级到本地逻辑，优先使用高可用网关选择实例，网关不可用时降级到默认模型。

## 技术实现

模型同步到网关通过创建 ApiInstanceCreateRequest 并调用网关的 createApiInstance 方法实现。最佳实例选择通过构建 SelectInstanceRequest 并调用网关的 selectBestInstance 方法，解析返回的 Provider 和 Model。事件驱动同步使用异步事件监听器，在模型创建时同步到网关，模型删除时从网关移除。

## 高可用网关设计

网关服务架构包含实例注册管理器、健康检查调度器和负载均衡选择器，数据存储使用 Redis。健康检查策略包括主动检查和被动检查两种方式。主动检查定期发送探测请求到所有实例，检查响应时间和可用性；被动检查根据调用结果更新实例状态。负载均衡算法支持轮询和响应时间两种策略。

## 负载均衡算法

轮询算法按顺序依次选择实例，响应时间算法选择平均响应时间最短的实例。选择算法可配置，支持按实际需求扩展。

## 配置设计

高可用配置包括网关连接参数、健康检查策略、亲和性类型和负载均衡策略。网关连接参数包括主机地址、端口、协议类型和超时时间。健康检查策略包括检查间隔、检查超时、失败阈值和成功阈值。亲和性类型支持 SESSION、USER 和 NONE 三种模式。负载均衡策略支持 ROUND_ROBIN、RANDOM、LEAST_CONNECTIONS 和 RESPONSE_TIME 四种算法。

## 关键流程

模型选择流程包含接收 LLM 调用请求、检查高可用是否启用、构建 SelectInstanceRequest、调用网关 selectBestInstance、网关根据策略选择最佳实例、返回 ApiInstanceDTO、解析 Provider 和 Model、使用选中的实例进行调用、调用结束上报结果到网关等步骤。

模型故障切换流程包含网关健康检查发现实例异常、标记实例为不健康、从可用实例池中移除、后续请求选择其他健康实例、定期重新检查故障实例、实例恢复后重新加入可用池等步骤。

## 错误处理

异常类型包括网关连接失败、选择超时、无健康实例、同步失败等。网关连接失败时降级到默认逻辑；选择超时时使用默认实例；所有实例不可用时返回错误或降级；模型同步到网关失败时记录错误日志，不影响主流程。

## 性能优化

模型同步异步执行，不阻塞主流程；结果上报异步处理；健康检查异步调度。网关 RPC 调用使用连接池，复用连接减少开销。缓存实例选择结果，减少网关调用次数。

## 监控指标

关键监控指标包括网关可用性、实例健康率、平均响应时间、故障切换次数、降级触发次数。告警规则包括网关不可用超过配置时间、健康实例少于配置数量、故障切换频率异常、降级频率超过阈值。日志记录包括模型同步日志、实例选择日志、故障切换日志、降级记录。

## 安全考虑

权限控制限制容器操作为管理员或拥有者。资源防滥用通过配置限制实现。API Key 等敏感信息加密存储，传输使用 HTTPS。
