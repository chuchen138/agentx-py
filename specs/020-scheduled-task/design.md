# 定时任务技术设计

## 概述

定时任务能力采用分层架构设计，遵循领域驱动设计（DDD）原则，提供灵活的定时任务创建、调度和执行能力。

## 技术架构

### 架构分层

系统采用四层架构：接口层处理 HTTP 请求，定义 DTO，参数校验；应用层负责业务流程编排，DTO 转换，调用领域服务（ScheduledTaskAppService）；领域层包含核心业务逻辑，实体模型，领域服务，任务调度（ScheduledTaskEntity、RepeatConfig、ScheduledTaskDomainService、TaskScheduleService、ScheduledTaskExecutionService、ScheduleTaskExecutor）；基础设施层负责数据库访问，数据持久化（ScheduledTaskRepository、ScheduledTaskMapper）。

### 核心组件

ScheduledTaskAppService 负责定时任务相关的业务流程编排，包括创建定时任务、更新定时任务、删除定时任务、获取任务详情、获取用户任务列表和按会话 ID 查询任务。TaskScheduleService 负责计算任务的下次执行时间，包括根据重复配置计算下次执行时间和处理时间边界问题（如跨天、跨月等）。ScheduledTaskExecutionService 负责任务的注册、调度和执行管理，包括注册任务到调度器、取消任务调度、重新调度任务、删除任务（包括取消调度）和监听任务执行事件。ScheduleTaskExecutor 负责实际执行任务，包括触发 Agent 执行、更新任务执行状态、处理执行异常和记录执行历史。

## 核心设计

### 任务实体和枚举

定时任务实体包含任务 ID、用户 ID、关联的 Agent ID、关联的会话 ID、任务内容、重复类型、重复配置（JSON 格式）、任务状态、上次执行时间、下次执行时间等字段。使用 UUID 生成唯一 ID，提供进度字段支持任务进度跟踪。RepeatType 枚举定义了 IMEDIATE（立即执行）、INTERVAL（间隔重复）、DAILY（每日重复）、WEEKLY（每周重复）、CUSTOM（自定义 Cron 表达式）等多种重复类型。ScheduleTaskStatus 枚举定义了 PENDING（待执行）、RUNNING（执行中）、COMPLETED（已完成）、FAILED（执行失败）、PAUSED（已暂停）等任务状态。

### 重复配置和执行时间计算

RepeatConfig 配置类存储重复类型相关的配置，包括间隔小时数（INTERVAL 类型使用）、执行时间 HH:mm（DAILY、WEEKLY 类型使用）、星期几列表（WEEKLY 类型使用，1-7）和 Cron 表达式（CUSTOM 类型使用）。TaskScheduleService 根据任务重复类型计算下次执行时间：间隔类型在上次执行时间基础上加上间隔小时数；每日类型计算下一天的指定时间；每周类型计算下一个符合星期几的指定时间；自定义类型解析 Cron 表达式计算。

### 任务调度和执行

ScheduledTaskExecutionService 使用 Spring 的 TaskScheduler 进行任务调度，包括注册任务到调度器、重新调度任务、取消任务调度和删除任务。任务执行时更新状态为执行中，发布任务执行事件，处理异常情况。ScheduleTaskExecutor 监听任务执行事件，调用 Agent 执行任务，更新任务状态为已完成，计算下次执行时间，重新调度任务。异常情况下更新任务状态为执行失败。

### 数据持久化

系统设计了定时任务表结构，包含任务 ID、用户 ID、Agent ID、会话 ID、任务内容、重复类型、重复配置、状态、执行时间等字段，并为常用查询字段建立索引。

## 关键设计决策

使用 Spring 内置调度器，集成方便，支持多种调度策略（固定延迟、Cron 表达式等），与 Spring 生态系统整合良好，减少外部依赖。任务执行通过事件触发，执行器和调度服务解耦，支持异步执行。支持多种重复类型满足不同场景，配置参数与重复类型绑定，便于扩展新的重复类型。任务状态有明确的转换规则，使用枚举定义状态，状态转换有业务校验。

## 性能优化

使用高效的调度算法，减少不必要的调度计算，支持任务批量注册。为常用查询字段建立索引，支持分页查询，缓存常用任务数据。同一时间限制任务执行数量，使用线程池控制并发，避免资源耗尽。执行历史定期归档，减少主表数据量，提升查询性能。

## 扩展性设计

新增重复类型的步骤包括在 RepeatType 枚举中添加枚举值、在 TaskScheduleService 中添加计算逻辑、在 RepeatConfig 中添加需要的配置字段、更新前端支持新的重复类型。支持自定义任务执行器，定义任务执行器接口，实现自定义执行逻辑。支持任务之间的依赖关系，在任务实体中添加依赖任务 ID 字段。支持将任务分组管理，在任务实体中添加任务分组字段。

## 集成与安全

### 模块集成

任务与会话绑定，任务执行时使用会话上下文，承载任务执行的会话环境。任务与 Agent 绑定，任务内容由 Agent 执行，支持 Agent 维度的任务管理。定时任务执行可计费，支持按任务次数或时长计费，记录任务执行用于成本分析。任务执行记录到执行追踪，支持查看任务执行的详细链路，便于问题排查和性能分析。

### 安全设计

用户只能管理自己的任务，任务访问需要权限验证，禁止跨用户任务访问。任务内容长度限制，防止恶意代码注入，敏感信息脱敏。记录任务创建、修改和删除操作，支持操作追溯。

### 数据一致性

任务创建和更新使用事务，任务执行状态更新使用事务，确保数据完整性。任务执行幂等，防止重复执行，使用分布式锁控制并发执行。任务执行结果及时更新，支持查询真实执行状态，异常情况下的超时处理。

## 技术栈

Spring Boot、Spring TaskScheduler、MyBatis-Plus、MySQL、Spring Event、Spring @Async。
