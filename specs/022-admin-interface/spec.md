# 管理后台（Admin Interface）

## 概述

管理后台模块提供官方服务商和官方工具的管理能力，支持后台管理员对官方资源进行创建、修改、审核和权限控制等功能。

## 功能需求

### 1. 官方服务商管理

**描述**：管理员可以创建和管理官方 LLM 服务商，所有用户均可使用官方服务商。

**功能**：
- **创建官方服务商**：创建新的官方服务商，标记为 isOfficial=true
- **修改服务商配置**：更新官方服务商的 API 密钥、配置参数等
- **设置管理员权限**：将服务商标记为管理员级别（setAdmin()）
- **密钥掩码处理**：修改服务商时，支持传入密钥掩码保留原有密钥

**要求**：
- 官方服务商对所有用户可见和可用
- 支持密钥的加密存储和安全传输
- 修改日志记录，追踪变更操作

### 2. 官方工具审核

**描述**：管理员可以审核用户发布的工具，审核通过后工具发布为官方工具。

**审核流程**：
1. 用户提交工具发布申请
2. 工具进入待审核状态
3. 管理员审核工具内容、接口、文档等
4. 审核通过后，工具标记为官方工具并发布

**审核内容**：
- 工具名称和描述
- 工具接口定义
- 工具文档
- 安全性检查
- 合规性检查

**要求**：
- 支持通过/拒绝审核
- 拒绝时提供审核意见
- 审核记录可追溯

### 3. 后台权限控制

**描述**：只有拥有管理员权限的用户才能执行管理后台的操作。

**权限要求**：
- 创建/修改官方服务商：需要 ADMIN 角色
- 审核/管理工具：需要 ADMIN 角色
- 查看官方资源：所有用户均可
- 管理员操作需要绑定到操作用户

**实现方式**：
- 基于角色的访问控制（RBAC）
- 操作审计日志
- 操作权限验证

### 4. 管理员服务分层

**描述**：管理后台服务按照领域进行分层，职责清晰。

**服务划分**：
- **AdminLLMAppService**：官方 LLM 服务商管理
- **AdminToolAppService**：官方工具审核和管理

**职责**：
- 应用层服务，协调领域层和接口层
- 处理管理后台的业务逻辑
- 权限验证和操作审计
- DTO 与实体转换

### 5. 官方资源查询

**描述**：支持查询和展示官方服务商和官方工具。

**查询功能**：
- 查询所有官方服务商列表
- 按类型、状态过滤服务商
- 查询官方工具列表
- 按审核状态、类型过滤工具

**要求**：
- 分页查询支持
- 排序支持
- 高性能查询

## 技术约束

- 管理后台服务独立于用户服务
- 遵循领域驱动设计（DDD）
- 支持细粒度权限控制
- 审计日志完整记录

## 性能要求

- 管理员操作响应时间 < 500ms
- 资源查询响应时间 < 200ms
- 支持批量操作和批量审核
- 支持并发管理操作

## 安全要求

- 强制权限验证
- 敏感信息脱敏显示（如密钥掩码）
- 操作审计日志
- 防止越权操作
- 支持操作回滚

## 合规要求

- 工具审核需记录审核意见
- 审核流程可追溯
- 敏感操作需要二次确认（如删除）
- 符合相关法律法规要求
